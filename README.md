# 当代人工智能 · 实验三

本分支 `experiment3` 独立存放 CIFAR-10 图像分类作业。

- [实验报告（PDF，5页）](实验三/report/实验三报告.pdf)
- [运行说明与实验设置](实验三/README.md)
- [训练代码](实验三/train.py)
- [实测结果](实验三/results/summary.json)

基础 CNN 测试准确率为 **84.86%**，残差与 SE 注意力改进 CNN 为 **87.77%**。两个模型均从零训练，各训练30轮，按验证集选取检查点；完整测试集包含10000张图片。

目录包含代码、模型检查点、训练日志、逐样本预测、图表和报告。原始数据集不入库，下载与复现方法见运行说明。
